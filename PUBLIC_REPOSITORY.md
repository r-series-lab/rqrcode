# Public Repository Boundary

This repository is intended to be public source code for rQrcode. It contains application source, documentation, tests, manifests, and synthetic examples only.

Do not commit QR payloads, images, screenshots, tokens, passwords, private keys, personal data, complete machine paths, private service URLs, generated build output, or local caches. The example URL `https://example.com` and similar test values are intentionally non-production placeholders.

The application processes QR content locally and does not publish a user's files or history through this repository. If sensitive data is found, do not copy it into a public issue; report it privately as described in [SECURITY.md](SECURITY.md).
